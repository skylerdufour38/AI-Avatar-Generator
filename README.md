# AI Avatar Generator

Upload an image, audio, and optional mask.

## Workflow

Upload Image
↓
Upload Audio
↓
Upload Mask (Optional)
↓
Enter Motion Prompt
↓
Select:
- 1080p
- 31 seconds
- Realistic

↓
Generate Video

↓
Preview MP4

↓
Download MP4
